Canonical educational Reels, Stories/Status, Highlights and attributed Response/Remix relationships for the Sabri Social Homeopathy Platform. Requires File 10.

== Description ==

File 11 owns the vertical educational Reel entity, 60–600 second rule, public discovery, ranking guardrails, moderation, private progress/history, source/safety context, Stories/Status, Highlights, Reel-to-Reel responses, well-being controls, youth-safe discovery and aggregate value insights.

File 10 remains the sole raw-media, playback, caption-object, rights, consent and secure-download owner. File 11 does not create a parallel media pipeline, interaction backend, social-post backend, notification transport, search index or design-token owner.

Public eligible Reels may be read without an account. Creating, publishing, reacting, saving, reporting, private history and preferences require the appropriate File 00 identity/capability state. Legacy published Reels without reviewed source/safety and caption/transcript evidence are fail-closed from public discovery until repaired.

== Installation ==

1. Install and activate a compatible File 10 release.
2. Install this ZIP with canonical root `reels-foundation-11`.
3. Activate only on production-like staging.
4. Run Reels Diagnostics and verify File 00/File 10 contract readiness.
5. Execute fresh-install, upgrade, role, media, privacy, accessibility, performance, restore and rollback matrices.
6. Obtain explicit Founder acceptance before production deployment.

== Frequently Asked Questions ==

= Does File 11 upload or transcode video? =
No. File 10 exclusively owns raw media and player operations.

= Are Stories separate unsafe media copies? =
No. Story/Status is a maximum-24-hour temporal projection of an already eligible Reel, with expiry and rights/consent revalidation.

= Can patient-case media be remixed automatically? =
No. Reuse is fail-closed unless the canonical consent owner verifies explicit reuse consent at creation, publication and every public read.

= Does the plugin force autoplay or endless sessions? =
No. Autoplay is user-controlled and muted; preferences provide session limits, natural stops, a single late-night reminder and private-history pause.
