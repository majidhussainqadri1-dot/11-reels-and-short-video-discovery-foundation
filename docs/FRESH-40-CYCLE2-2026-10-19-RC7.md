## Application-code defects demonstrated and corrected **before clean final 40-round run**

- **C2-F11-001:** PHP array-to-string answer comparison let malformed learning-quiz submissions be graded incorrectly. Fixed with type-aware, order-independent single/multiple-choice and normalized true/false matching.
- **C2-F11-002:** Quiz submissions omitted their own rate-limited, transactionally coupled audit/outbox evidence. Added transaction and opaque actor identity in event evidence with private/no-store response.
- **C2-F11-003:** Public Series read did not revalidate revoked or hidden Reel references. Added current fail-closed File 11 checks and data-minimized public projection.
- **C2-F11-004:** Empty Series could be created; now requires 1–100 current public Reel refs.
- **C2-F11-005:** Reusable public Study Tools context bypassed safe Series projection; now consumes only current-safe Series records.
- **C2-F11-006:** File 16 AI context source objects could contain stale/withdrawn evidence, or knowledge cards with unverified auxiliary refs. Added current-source validation of every File 06 reference, including remedy/disease/book/source refs, with no source-free fallback.
- **C2-F11-007:** AI context citation and chapter metadata lacked strict current source and File 10 duration-range revalidation. Added verified source and 60–600-second timestamp restrictions.
